  1. Open Work Mode in the FoxESS app or website.
  2. Under Advanced, enable Mode Scheduler.
  3. Open Mode Scheduler settings.
  4. Set Remaining Time Mode to Self-Use.
  5. Save the FoxESS settings.

Mode Scheduler applies this app’s periods. Self-Use applies outside those periods.

Complete this preparation before enabling Smart Charging automation.

ESP32 firmware update

Update from this project’s GitHub release over Wi-Fi. USB is required once to install OTA-capable firmware.

Automation suspends automatically during installation. Its saved state returns after restart. Monitoring can stop briefly.

Select Check GitHub for updates.

Optional Clean update

Default updates keep your settings. Clean update deletes all accounts, Wi-Fi, access protection, rules and saved History after a successful boot.

Clean update requires USB configuration again. The inverter keeps its existing schedule.

History storage

One hourly batch at most. Saved records are retained for 60 days. Recent unsaved readings can be lost after power loss.
