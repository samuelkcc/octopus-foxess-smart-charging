# Prepare your accounts

[Back to the project](../README.md) · [Choose a setup guide](../README.md#choose-your-setup-guide)

This page covers credentials shared by the editions. It does not install firmware or enable automation.

| Service | Required details | Optional details |
|---|---|---|
| Octopus Energy | Account number and API key | None |
| FoxESS | Inverter serial number and official REST API token | Cloud username and password for WebSocket telemetry |

## Octopus account and API key

Use the Octopus account connected to your Intelligent Octopus Go vehicle or charger.
An account number identifies your energy account. It is not your electricity meter serial number or MPAN.

1. Open your [Octopus account dashboard](https://octopus.energy/dashboard/).
2. Sign in to your energy account.
3. Open **Personal details**.
4. Open **Developer settings**.
5. Select **API access**.
6. If no key exists, create an API key.
7. Copy the API key into the setup tool's **Octopus API key** field.
8. Copy your account number into **Account number**.

[Octopus API access](https://octopus.energy/dashboard/new/accounts/personal-details/api-access) opens the account API page after sign-in.
If the layout changes, follow the current [official API access instructions](https://octopus.energy/help-and-faqs/articles/how-do-i-access-the-octopus-api/).

Use the customer API key, not your Octopus login password.
The app does not need your Octopus password.

## FoxESS inverter and REST API token

The token field accepts the API key generated by FoxESS Cloud.
It is separate from your FoxESS login password.

1. Open [FoxESS Cloud](https://www.foxesscloud.com/).
2. Sign in with an account that can access your inverter.
3. Open **User profile** or **Personal centre**.
4. Open **API management**.
5. Generate an API key if necessary.
6. Copy that key into the setup tool's **FoxESS API token** field.
7. Open your inverter's device details.
8. Copy the inverter serial number into **Inverter serial number**.

If the new interface hides API management, try the [personal centre](https://www.foxesscloud.com/user/center).
FoxESS may direct API management to its OpenPlatform portal. Follow the link from the official Cloud website.
The [official Open API documentation](https://www.foxesscloud.com/public/i18n/en/OpenApiDocument.html) describes API-key management and request limits.

Use the inverter serial number. Do not use the Wi-Fi data logger serial number.
If you replace a key, update any other integrations that use it.

## Optional FoxESS WebSocket login

ESP32, Pi, and Portable can use optional live telemetry instead of routine REST readings.
Pi uses Save & Test Live WS. Follow its native Configuration instructions.
The HTML web edition uses its own Google relay setup.

Use the username and password that you normally enter on the FoxESS Cloud website.
The account must have access to the same inverter used by the REST API.

1. If you want live telemetry, enter **FoxESS cloud username** and **FoxESS cloud password**.
2. On ESP32, select **Save accounts** in Dashboard Settings → Account setup.
3. Select **Test all APIs**.
4. Wait for a successful fresh reading.
5. Select your edition's WebSocket telemetry mode.
6. Save that selection.

If you do not need WebSocket, leave the optional login blank and use REST.
WebSocket supplies read-only measurements. Schedule commands and confirmation always use official REST.
A login test can sign the FoxESS mobile app out.

## ESP32 network details

- Prepare the name and password for a 2.4 GHz Wi-Fi network.
- Keep dashboard port **8787** unless you need another port.
- Prefer a DHCP reservation on your router for a stable address.
- For a fixed IP, prepare the address, gateway, subnet mask, and DNS server.
- Check that the selected address is outside conflicting allocations.

The deployment tool can scan Wi-Fi and suggest an address. A silent device can still own a suggested address.
Use USB to change Wi-Fi, IP, or port settings. Incorrect network settings can otherwise make the dashboard unreachable.

## Verify your setup

1. Open the guide for your chosen edition.
2. Enter your own credentials in that edition's setup controls.
3. Run the available API tests.
4. For ESP32 deployment, wait for Wi-Fi and IP verification before saving.
5. In ESP32 Dashboard Account setup, select **Test all APIs**.
6. Before enabling control, disable other automation hosts for this inverter.

Never put real keys or passwords in screenshots, issue reports, public files, or Git commits.
